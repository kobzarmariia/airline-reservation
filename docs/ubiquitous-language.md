| Term                      | Meaning                                                                          |
| ------------------------- | -------------------------------------------------------------------------------- |
| **Flight**                | A scheduled journey between two airports at a specific departure time            |
| **Passenger**             | A person included in a reservation and intending to travel on a flight           |
| **Reservation**           | A booking that holds flight inventory for one or more passengers                 |
| **Pending Reservation**   | A reservation awaiting payment confirmation                                      |
| **Confirmed Reservation** | A reservation for which payment has been successfully completed                  |
| **Expired Reservation**   | A reservation whose payment deadline has passed                                  |
| **Cancelled Reservation** | A reservation cancelled before the flight                                        |
| **Seat**                  | A specific seat on an aircraft that may be assigned to a passenger               |
| **Seat Assignment**       | Association of a specific seat with a passenger for a flight                     |
| **Fare**                  | The price and conditions associated with a passenger's journey                   |
| **Booking Window**        | Period during which new reservations may be created for a flight                 |
| **Hold**                  | Temporary allocation of flight inventory while a reservation is awaiting payment |
| **Hold Expiration**       | Time at which inventory held by an unpaid reservation is automatically released  |
| **Availability**          | Flight inventory that can currently be reserved                                  |
| **Capacity**              | Maximum number of passengers that can be accommodated on a flight                |
| **Payment**               | Payment attempt associated with a reservation                                    |
| **Confirmation**          | Transition of a pending reservation to confirmed after successful payment        |
| **Cancellation**          | Termination of a reservation according to the applicable cancellation rules      |
