# Airline Reservation System

A pet project built to learn and apply **Domain-Driven Design (DDD)** principles using a realistic airline reservation domain.

## Goals

- Practice Strategic and Tactical DDD
- Build a rich domain model with complex business rules
- Explore Aggregates, Value Objects, Domain Events, and Bounded Contexts
- Follow Clean Architecture principles
- Improve backend architecture and design skills

## Tech Stack

- NestJS
- Prisma ORM
- MongoDB
- TypeScript
- Jest
- Swagger

## Planned Bounded Contexts

- Flight Management
- Reservation
- Check-in
- Boarding
- Payments
- Loyalty Program
- Notifications

## Core domain

Reservation

## Project Status

🚧 Work in progress.

The project will be developed incrementally while studying **Domain-Driven Design Distilled** by Vaughn Vernon.
